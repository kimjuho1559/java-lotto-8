# java-lotto-precourse

## 프로젝트 소개
사용자가 로또 금액(개당 1000원)을 입력하면(1000원으로 나누어 떨어지지않으면 예외처리) 1 ~ 45까지 중복되지 않는 6개의 숫자를 입력받는다.
(1 ~ 45사이의 숫자가 아닐 경우 예외처리 후 다시 입력 받음)

사용자의 번호 뽑은 뒤 중복되지 않는 숫자 6개 뽑은 뒤 + 보너스 숫자 1개를 뽑는다.

사용자의 번호와 로또 번호를 비교하여 당첨내역을 출력한다.

당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
- 1등: 6개 번호 일치 / 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
- 3등: 5개 번호 일치 / 1,500,000원
- 4등: 4개 번호 일치 / 50,000원
- 5등: 3개 번호 일치 / 5,000원

후 총 수익률을 소수점 둘째 자리에서 반올림한다.

## 기능 정리
1. 사용자의 로또 구매 금액 입력
2. 1000원으로 나누기 (1000원으로 나누어 떨어지지 않을 경우 예외처리)
3. 당첨 번호 입력 (1~45사이의 숫자가 아닐 경우 예외처리)
4. 로또 갯수만큼 6개의 랜덤 로또 번호 생성 (오름차순 정렬)
5. 사용자의 당첨 번호화 랜덤 로또 번호와 비교
6. 당첨 내역을 출력 (당첨 기준으로)
7. 수익률 출력 (소수점 둘째 자리에서 반올림)
